## 常见问题

**骨灰寄存小程序能解决哪些具体业务?**

骨灰寄存小程序覆盖四类高频业务:寄存登记、格位信息查询、到期自动提醒与在线续费。格位编号、区域位置、寄存人关系、有效期与历史续费记录统一入库,家属无需到馆即可办理,馆内人员从纸质台账转向系统化档案维护,查询与核对效率同步提升。

**预约祭扫系统如何应对清明高峰人流?**

预约祭扫系统通过分时段放号、人数限额、实名登记与入园核验四重机制实现主动限流。管理端可按日期与时段灵活配置放号规则,实时查看预约量与到访数据,并据此提前安排人力与安保资源;预约数据逐年沉淀后,可作为清明、冬至服务预案的排班依据。

**代客祭扫公众号如何保证服务过程可信?**

代客祭扫公众号以“委托—执行—反馈”三个节点构成完整闭环:家属在线选择套餐、填写委托信息并完成支付;服务执行后,陵园以照片、视频形式回传留痕;家属在手机上即可核验服务是否按时、按标准执行,委托内容与执行结果可一一对应。

**殡葬行业数字化项目能否分阶段实施,预算有限怎么办?**

可以,该项目采用“先高频、后延伸”路径:寄存服务小程序、预约祭扫系统、代客祭扫公众号三端可拆分独立上线。预算有限时先上线骨灰寄存小程序解决档案与续费问题;高峰压力突出时优先建设预约祭扫系统;异地家属占比高的陵园可先落地代客祭扫服务。分阶段投入既控制单次预算,也让每阶段效果可被单独验证。

**老年家属不熟悉手机操作怎么办?**

方案在界面与操作路径上做适老化设计,包括放大关键信息字号、减少单页操作步骤、将高频功能置于首屏,并保留线下窗口辅助通道并行。数字化的目标是增加办理方式,而非取消原有方式,确保服务不因数字化而排斥任何群体。

**三端系统的数据是否互通?**

互通。寄存服务小程序、预约祭扫系统与代客祭扫公众号共享同一套用户身份与业务数据底座:家属一次实名认证即可跨场景办理寄存在线续费、祭扫时段预约与代祭服务委托;陵园管理端在同一后台完成人员、格位、时段、订单与统计数据的集中管理。
